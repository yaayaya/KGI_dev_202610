## 題目一：權證發行風險監控與避險試算系統

原 PDF：第 2～3 頁。

### 1. 故事背景

公司權證發行部門需監控標的股價對權證理論價值的影響。當股價變動時，系統須即時試算交易員應在現貨市場買入或賣出的避險張數（Delta Hedging），以維持風險中性。

### 2. 資料庫結構（Table Schema）

#### A. 權證基本檔（Warrant_Master）

| 欄位 | 型態 | 說明 |
| --- | --- | --- |
| `Warrant_ID` | `VARCHAR(10)` | PK，權證代碼（如：03001P） |
| `Strike_Price` | `DECIMAL(18,4)` | 履約價格（執行價） |
| `Conversion_Ratio` | `DECIMAL(18,4)` | 行使比例（例：0.1 代表 10 換 1） |
| `Warrant_Type` | `VARCHAR(4)` | 類型（CALL / PUT） |
| `Position_Qty` | `INT` | 庫存張數（發行商持有部位） |

#### B. 試算日誌表（Warrant_Trial_Log）

| 欄位 | 型態 | 說明 |
| --- | --- | --- |
| `Log_ID` | `INT (Identity)` | PK，自動編號 |
| `Warrant_ID` | `VARCHAR(10)` | 關聯之權證代碼 |
| `Market_Price` | `DECIMAL(18,4)` | 試算時輸入的標的股價 |
| `Theory_Price` | `DECIMAL(18,4)` | 計算出之理論價值 |
| `Hedge_Qty` | `DECIMAL(18,2)` | 建議避險張數 |
| `Created_Time` | `DATETIME` | 存檔時間 |

### 3. 核心計算邏輯（C# API）

#### 1. 理論價值計算

```text
CALL：Max(0, (標的價 - 履約價) × 行使比例)
PUT ：Max(0, (履約價 - 標的價) × 行使比例)
```

#### 2. 避險張數計算（Delta 簡化模型）

```text
避險張數 = 庫存張數 × 行使比例 × Delta
```

**Delta 定義：**

| 狀態 | 判斷條件 | Delta |
| --- | --- | --- |
| 價內（ITM） | 標的價 > 履約價（Call），或標的價 < 履約價（Put） | 0.8 |
| 價平（ATM） | 標的價 = 履約價 | 0.5 |
| 價外（OTM） | 其餘狀況 | 0.2 |

#### 3. 防禦性檢查

標的價輸入 **<= 0** 時，API 需回傳錯誤，禁止存檔。

### 4. UI 畫面詳細描述（WinForm 或 Vue.js）

#### 權證導覽列

左側顯示 **800 筆測試資料列表**，支援代碼關鍵字搜尋。

#### 動態試算面板

- 輸入「標的股價」時，畫面需即時反映「理論價值」與「建議避險張數」。
- 提供「儲存試算結果」按鈕，點擊後寫入 `Warrant_Trial_Log`，並跳出 Toast 成功提示。

#### 歷史明細區

底部表格列出該檔權證**最近 10 筆存檔紀錄**，包含時間與計算結果。

## 題目二：借券擔保品「維持率」監控與異常作業平台

原 PDF：第 4～5 頁。

### 1. 故事背景

借券業務中，借券人需提供擔保品。當借出標的價格上漲導致維持率不足時，需發出追繳。此任務考驗 CSV 匯入、SQL 大量比對與資料視覺化呈現能力。

### 2. 資料規格（Data Dictionary）

#### A. 借券合約表（Lending_Contract）

| 欄位 | 型態 | 說明 |
| --- | --- | --- |
| `Contract_No` | `VARCHAR(20)` | PK，合約編號（例：CT2026042401） |
| `Stock_ID` | `VARCHAR(10)` | 借出標的代碼（如：2330） |
| `Borrowed_Qty` | `INT` | 借出數量（張） |
| `Collateral_Val` | `DECIMAL(18,2)` | 擔保品總市值（現金 + 抵押券） |

#### B. 外部 CSV 資料（Market_Price.csv）

```csv
Stock_ID,Closing_Price,Trade_Date
2330,815.00,20260424
2317,155.50,20260424
```

### 3. 處理流程（ETL & SQL）

#### 1. C# 匯入邏輯

撰寫功能將 CSV 上傳並解析，存入資料庫。

#### 2. 維持率計算（Set-based SQL）

```text
維持率（%）= [擔保品總市值 / (借出數量 × 1000 × 今日收盤價)] × 100%
```

**技術要求：**必須使用 SQL `JOIN` 一次性計算所有合約（約 **1,000 筆**），**嚴禁使用迴圈逐筆查詢**。

#### 3. 狀態定義

- 維持率 **< 140%** 為「預警（Warning）」。
- 維持率 **< 120%** 為「處置（Call）」。

### 4. UI 畫面詳細描述（WinForm 或 Vue.js）

#### 數據儀表板（Dashboard）

頁面頂端呈現三種狀態（正常／預警／處置）的件數總計。

#### 資料監控表格

- 顯示合約明細。維持率欄位需有顏色背景：**< 120% 紅色、< 140% 黃色、其餘綠色**。
- 具備「僅顯示異常」的過濾器切換開關。

#### CSV 上傳區

支援拖曳上傳，上傳後系統自動執行比對計算並重新整理表格。

## 題目三：借券利息結算引擎與維運同步監控工具

原 PDF：第 6～7 頁。

### 1. 故事背景

公司每日凌晨執行利息結算作業。由於涉及帳務，絕對不允許「重複執行」，且需保證「明細總額與批次總額完全一致」。此任務需建立 Web API 結算邏輯並開發 WinForm 監控工具。

### 2. 資料庫結構（Table Schema）

#### A. 結算批次主表（Interest_Batch）

| 欄位 | 型態 | 說明 |
| --- | --- | --- |
| `Batch_ID` | `VARCHAR(20)` | PK，結算編號（例：20260424_INT） |
| `Expected_Amt` | `DECIMAL(18,4)` | 主表預計總額（校驗用） |
| `Process_Status` | `INT` | 0：待處理，1：處理中，2：結算成功，9：失敗 |
| `Progress_Rate` | `INT` | 進度百分比（0-100） |

#### B. 結算明細表（Interest_Detail）

| 欄位 | 型態 | 說明 |
| --- | --- | --- |
| `Detail_ID` | `INT (PK)` | 自動編號 |
| `Batch_ID` | `VARCHAR(20)` | 關聯主表 |
| `Daily_Interest` | `DECIMAL(18,4)` | 單筆合約算出的利息 |

### 3. 核心處理邏輯（C# RESTful API）

#### 1. 冪等性檢查（Idempotency）

API 啟動時先檢查 `Process_Status`。若已為 **2（Success）**，回傳錯誤，禁止重複結算。

#### 2. 總額一致性校驗

- 計算完成前，執行 SQL 比對：`SUM(Daily_Interest)` 是否等於 `Expected_Amt`。
- 若差異 **> 0.0001**，必須執行 `Transaction.Rollback()`，並將狀態改為 **9（失敗）**。

#### 3. 異步進度更新

在處理大量資料期間，需同步更新 `Progress_Rate`。

### 4. UI 畫面詳細描述（Vue & WinForm）

#### Web 端（Vue.js）

顯示各批次列表及「啟動結算」按鈕，點擊後按鈕需變更為 Loading 狀態並停用。

#### WinForm 監控端

- 使用 ProgressBar 與百分比文字呈現即時進度（**每 5 秒輪詢一次 API**）。
- **異常告警：**若結算狀態變為 **9（失敗）**，視窗背景需變為紅色並顯示錯誤日誌。

## 題目四：券商股務代理作業管理系統（Stock Affairs Agency System）

原 PDF：第 8～10 頁。

### 1. 故事背景

券商之股務代理部門負責上市櫃公司之股務行政作業，核心職能包含：

- **股東名簿管理：**股票過戶、質權設定與撤銷。
- **會議籌辦：**代理召開股東常會／臨時會、寄發開會通知、處理委託書。
- **利息與股利發放：**現金股利計算與發放、增資股票配發。

由於股權資料高度敏感，且涉及股東權益與法遵要求，本系統需確保**資料正確性、可追溯性、批次作業一致性與操作稽核能力**。

### 2. 資料庫結構（Table Schema）

#### A. 股東主檔（Shareholder_Master）

| 欄位 | 型態 | 說明 |
| --- | --- | --- |
| `Shareholder_ID` | `VARCHAR(20)` | PK，股東代碼 |
| `Shareholder_Name` | `NVARCHAR(50)` | 股東姓名 |
| `ID_No` | `VARCHAR(20)` | 身分證／統編 |
| `Address` | `NVARCHAR(100)` | 通訊地址 |
| `Created_Time` | `DATETIME` | 建檔時間 |

#### B. 股東名簿（Shareholding_Register）

| 欄位 | 型態 | 說明 |
| --- | --- | --- |
| `Company_Code` | `VARCHAR(10)` | PK，公司代碼 |
| `Shareholder_ID` | `VARCHAR(20)` | PK，股東代碼 |
| `Share_Qty` | `INT` | 持股股數 |
| `Pledge_Qty` | `INT` | 已設定質權股數 |
| `Last_Update_Time` | `DATETIME` | 異動時間 |

#### C. 股權異動紀錄（Share_Transfer_Log）

| 欄位 | 型態 | 說明 |
| --- | --- | --- |
| `Transfer_ID` | `INT (Identity)` | PK |
| `Company_Code` | `VARCHAR(10)` | 公司代碼 |
| `From_Shareholder` | `VARCHAR(20)` | 出讓人 |
| `To_Shareholder` | `VARCHAR(20)` | 受讓人 |
| `Transfer_Qty` | `INT` | 過戶股數 |
| `Transfer_Type` | `VARCHAR(10)` | TRANSFER / PLEDGE / UNPLEDGE |
| `Created_Time` | `DATETIME` | 操作時間 |

#### D. 股東會紀錄（Shareholders_Meeting）

| 欄位 | 型態 | 說明 |
| --- | --- | --- |
| `Meeting_ID` | `VARCHAR(20)` | PK |
| `Company_Code` | `VARCHAR(10)` | 公司代碼 |
| `Meeting_Type` | `VARCHAR(10)` | AGM / EGM |
| `Meeting_Date` | `DATE` | 開會日期 |
| `Notice_Sent_Flag` | `BIT` | 是否已寄發開會通知 |

#### E. 股利發放批次（Dividend_Batch）

| 欄位 | 型態 | 說明 |
| --- | --- | --- |
| `Batch_ID` | `VARCHAR(20)` | PK |
| `Company_Code` | `VARCHAR(10)` | 公司代碼 |
| `Dividend_Type` | `VARCHAR(10)` | CASH / STOCK |
| `Dividend_Per_Share` | `DECIMAL(18,4)` | 每股配發 |
| `Total_Amount` | `DECIMAL(18,2)` | 預計總金額 |
| `Status` | `INT` | 0：待處理，1：完成 |

### 3. 核心處理邏輯（C# RESTful API）

#### A. 股票過戶／質權設定 API

- 單筆或批次異動。
- 必須使用 **Transaction** 保證：
  - 出讓人股數扣減。
  - 受讓人股數增加。
  - `Share_Transfer_Log` 寫入成功。
- 禁止股數不足、質押超額。

#### B. 股東會通知產生

- 依 `Meeting_Date` 自動篩選**基準日股東名簿**。
- 產生開會通知清單（可模擬 Email / PDF）。
- 發送後更新 `Notice_Sent_Flag`。

#### C. 股利發放計算

依股權比例計算：

```text
現金股利 = 股數 × 每股金額
股票股利 = 股數 × 配股率
```

- 所有明細加總需 **100% 與批次主檔 `Total_Amount` 相符**。
- API 需具備**冪等性（同一 `Batch_ID` 不可重複執行）**。

### 4. UI 畫面詳細描述（WinForm 或 Vue.js）

#### 股務代理後台 Dashboard

- 公司快速切換。
- 股東總人數／總發行股數／已質押比例。

#### 股東名簿管理頁

- 股東列表（查詢／排序）。
- 操作按鈕：
  - 股票過戶。
  - 質權設定／撤銷。

#### 股東會管理頁

- 股東會列表。
- 「產生並寄發開會通知」按鈕。
- 顯示已通知／未通知狀態。

#### 股利發放頁

- 批次列表。
- 試算金額 Preview。
- 「確認發放」後狀態鎖定。
