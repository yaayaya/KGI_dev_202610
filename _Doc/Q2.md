# Q2：借券維持率監控

依行情 CSV 的收盤價，監控借券合約的擔保品維持率。頁面入口為 `/lending`，可由共用選單切換至「借券維持率監控」。

## 操作方式

1. 按「匯入行情」展開匯入區，再拖曳或選取一份 CSV；上傳區顯示檔名與大小，原有監控資料保持不變。手動收合會保留選檔，成功匯入後自動收合。
2. 可按「查看預覽」開啟彈窗，檢視前十筆股票代碼、收盤價與交易日期。關閉彈窗後保留選檔，預覽不是匯入必要步驟。
3. 按「確認匯入」，後端完整驗證檔案；通過後在單一交易內寫入該日行情。
4. 成功後顯示匯入筆數與日期，清除選檔並更新監控資料。若行情已匯入但刷新失敗，單獨提示重新整理，不將匯入誤報為失敗。

頂部以單列摘要顯示全體合約及各狀態件數，合約表格使用其餘工作區。合約編號與股票代碼可用關鍵字搜尋，並搭配狀態選單或「僅顯示異常」；這些條件只篩選明細，不改變全體統計。尚未有行情的合約顯示待補價，不能算作正常。

表格可選每頁 25、50、100 筆，提供首頁、上一頁、下一頁、末頁；切換分頁、條件、每頁筆數或更新資料後，表身會回到頂端並保留水平位置。手機可橫向捲動查看完整欄位；短視窗保留工作區捲動，避免條件或分頁被裁切。

## CSV 格式與匯入規則

範例檔：[一般行情](examples/Market_Price.csv)、[上漲行情](examples/Market_Price_Up.csv)、[下跌行情](examples/Market_Price_Down.csv)。三份檔案都涵蓋二十檔股票，日期皆為 2026/10/28，可依序匯入觀察同日改價後的維持率與狀態變化。

```csv
Stock_ID,Closing_Price,Trade_Date
2330,815.00,20260424
2317,155.50,20260424
```

上列只是格式示意；正式匯入須涵蓋全部借券合約標的，請使用完整範例檔。

- 編碼為 UTF-8，可包含 BOM；固定逗號分隔，支援 CSV 引號及標準換行。
- 表頭為 `Stock_ID,Closing_Price,Trade_Date`。股票代碼作為字串保留，長度一至十碼，接受英數字、點、底線與連字號，並以英數字開頭；匯入時去除欄位周圍空白、英文字母轉大寫。
- 收盤價必須大於零，最多四位小數，且符合 `DECIMAL(18,4)`。
- 日期使用 `yyyyMMdd`，每份檔案僅接受一個有效交易日；同一股票不可重複。
- 單檔最多 2 MiB、10,000 筆行情。格式錯誤回傳所在資料列與原因；整批失敗時不寫入部分行情。
- 需完整覆蓋所有合約標的；缺價整批拒絕，不沿用前一天價格。檔案可以包含目前沒有合約的股票。
- 同日重傳會在交易內替換該日完整行情，不重複新增。其他日期的行情會保留。
- 初次開啟預設查詢最新行情日期。匯入後顯示該份檔案的交易日，即使匯入的是較舊日期，也不與其他日期混算。

Papa Parse 僅負責可選的前十筆預覽，`dynamicTyping: false` 保留字串，`worker: false` 避開已知 Vite 8 Worker 問題。預覽通過不代表完整檔案有效；後端 CsvHelper 會重新解析及驗證全部內容。CsvHelper 固定使用 `33.1.0`，避免混用 34 版改寫後的 API。

## 維持率與狀態

```text
維持率（%）= 擔保品總市值 ÷（借出張數 × 1000 × 收盤價）× 100
```

| 狀態 | 條件 | 維持率背景 |
| --- | --- | --- |
| 處置（Call） | 小於 120% | 紅色 |
| 預警（Warning） | 大於等於 120%、小於 140% | 黃色 |
| 正常（Normal） | 大於等於 140% | 綠色 |
| 未計算（Unpriced） | 所選日期沒有行情 | 中性色 |

SQL 以一次 JOIN 計算全部合約，禁止逐筆查詢。狀態按精確數值判斷，顯示維持率才取兩位小數；接近界線的資料可能顯示 `120.00%` 仍屬處置，或顯示 `140.00%` 仍屬預警。借出張數乘以 1000 前轉為 decimal，避免整數中間溢位。金額、價格與比例由 API 以十進位字串傳回，前端不重新計算。

## API

| 方法與路徑 | 用途 | 成功狀態 |
| --- | --- | --- |
| `GET /api/lending/monitor?tradeDate=` | 取得指定交易日的合約、全體件數與行情日期；日期省略時取最新日 | 200 |
| `POST /api/lending/market-prices/import` | 以 `multipart/form-data` 的 `file` 欄位匯入 CSV | 200 |

查詢日期格式為 `yyyy-MM-dd`，與 CSV 的 `yyyyMMdd` 不同。查詢回應包含 `tradeDate`、`totalCount`、`normalCount`、`warningCount`、`callCount`、`unpricedCount`、`contracts`。無行情時預設查詢的 `tradeDate` 為 null；有合約但缺價時，其收盤價及維持率為 null。匯入回應包含交易日 `tradeDate` 與行情筆數 `importedCount`。

錯誤沿用 HTTP 狀態及 ProblemDetails。匯入不會自動重試；若網路中斷而無法確認結果，先重新整理監控資料再決定是否重送。

## 資料庫與維護入口

- 新環境：依 README 執行既有全量建表、索引及預設資料三份腳本，包含 Q1、Q2。
- 既有 `KGI`：只執行 [AddQ2Lending.sql](../Kgi.Tests/Database/Scripts/InitTestDb/DbScript/AddQ2Lending.sql) 及 [Preload.sql](../Kgi.Tests/Database/Scripts/InitTestDb/Preload.sql)，保留原有資料。
- `Lending_Contract` 保留題目指定四欄；`Market_Price` 依股票及交易日唯一保存價格。維持率與狀態不落表，以避免行情更新後留下舊結果。
- 預載資料提供 1,000 筆合成合約，涵蓋 20 檔股票、600 種借出張數及 1,000 種擔保品市值；各股票合約數不同，不再固定每檔五十筆或循環六種維持率。合約值全部直接列在 `Preload.sql` 的 `VALUES`，可逐筆修改，SQL 不負責產生亂數。不預先匯入行情，首次開啟顯示未計算。
- 三份 CSV 的收盤價依股票不同，並非全部一百元。搭配本版新初始化的合約，一般行情預期為正常 461、預警 298、處置 241 件；上漲行情為正常 392、預警 98、處置 510 件；下跌行情為正常 753、預警 93、處置 154 件。這些資料不代表真實價格或券商部位。
- 前六筆合約保留以一百元行情驗證 120%／140% 邊界的固定案例，其餘合約數值分散。`Preload.sql` 只補缺少的編號，不覆寫既有合約，所以修改腳本不會自動改變已建立的資料庫；既有舊版示範資料不可直接套用上述件數。
- 後端維護入口為 `Kgi.Api/Features/Lending/`；前端為 `Kgi.Web/src/features/lending/`。共用選單、主題、Axios 與 OpenAPI／Orval 沿用現有流程。

本次範圍為匯入與監控；實際追繳通知、案件簽核、合約 CRUD 與排程不包含在 Q2 首版。

## 驗證方式

後端測試沿用 `dotnet test Kgi.Tests/Kgi.Tests.csproj`。純 CSV 解析測試不需要資料庫；DB/API 測試只有在明確設定 `KGI_TEST_CONNECTION_STRING` 與 `KGI_ALLOW_DB_REBUILD=1` 時才執行，且會重建 `KGI_Test`。不要因為 DB 測試被跳過而視為資料庫已通過驗證。

前端由使用者人工檢查：

1. 桌面與手機選單都能切換 Q1、Q2，Q1 原有操作維持正常。
2. 匯入區預設收合，展開後可選檔／拖曳，收合後再展開仍保留選檔；按鈕才開預覽，關閉後保留選檔。快速換檔不出現舊檔預覽。
3. 預覽只顯示前十筆，股票前導零與價格字串不遺失；錯誤表頭及破損 CSV 顯示原因。
4. 上傳進行中不能重複送出；成功後清除選檔、更新日期、統計及表格；刷新失敗只提示刷新失敗。
5. 正常／預警／處置的文字與背景一致，120% 屬預警、140% 屬正常；搜尋、狀態與異常開關只影響明細，清除條件可還原全部合約。捲動後換頁、變更條件或每頁筆數都回到表身頂端；橫向位置保留，分頁不漏資料。
6. 空檔、多檔、超大檔、錯誤日期、重複股票、缺價、無效價格匯入失敗，保留原有資料；同日重匯不產生重複行情。
