# Q1：權證試算

查詢權證，依標的股價試算理論價值與建議避險張數，頁面入口為 `/warrants`。

## 操作

1. 搜尋權證代碼或篩選 CALL／PUT，選擇一筆權證。
2. 輸入標的股價，自動顯示試算預覽。
3. 按「儲存試算」後，先在確認視窗核對權證、股價及試算結果，再確認寫入；成功後清空輸入，並更新最近十筆歷史。按 Enter 同樣需要確認，取消不會寫入。

## 計算規則

- 股價須大於零、最多四位小數，且符合 `DECIMAL(18,4)`。
- CALL 價差＝股價－履約價；PUT 價差＝履約價－股價。
- 理論價值＝價差與零取較大值 × 行使比例，四捨五入至四位小數。
- 建議避險張數＝庫存張數 × 行使比例 × Delta，四捨五入至兩位小數；價內／價平／價外的 Delta 為 `0.8`／`0.5`／`0.2`。
- 預覽不寫入資料庫；儲存時由後端重算。時間以 UTC 儲存、台北時間顯示。

## API

| 方法與路徑 | 用途 | 成功狀態 |
| --- | --- | --- |
| `GET /api/warrants?keyword=` | 查詢權證清單 | 200 |
| `POST /api/warrants/{id}/preview` | 預覽試算 | 200 |
| `POST /api/warrants/{id}/trials` | 儲存試算 | 201 |
| `GET /api/warrants/{id}/trials` | 最近十筆試算紀錄 | 200 |

`{id}` 為權證代碼；預覽與儲存輸入例如 `{ "marketPrice": "120.0000" }`。無效輸入回傳 `400`，查無權證回傳 `404`。

## 設計架構

- 前端：Vue 元件呈現權證清單、試算與歷史；`useWarrantWorkspace` 管理選券、預覽及儲存狀態。
- 後端：`Controller → WarrantService → WarrantDao → KGI`，Service 負責驗證與金融計算，Dao 透過 Dapper 存取資料。
- 資料：權證主檔與試算紀錄分開保存，預覽不寫入，儲存時由後端重算。
